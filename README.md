# demo

Кликабельные демо-макеты продуктов.

Каждый макет — один статический HTML-файл: разметка, стили и логика внутри. Работает в браузере без сервера, без сборки и без установки. Открывается по ссылке и сразу нажимается.

Опубликовано: **https://demo.botneversleeps.com**

---

## Зачем это нужно

Заказчику трудно оценить продукт по техническому заданию. Макет решает это за одну встречу: клиент проходит путь пользователя руками и сам видит, что получит. Собирается за несколько часов вместо недель разработки — и позволяет поймать неверные предположения до того, как написан рабочий код.

## Как устроено

- каждая папка — отдельный макет;
- внутри `index.html` — весь макет целиком, внешних зависимостей нет (кроме веб-шрифтов);
- состояние живёт в памяти страницы: сценарий заранее прописан, кнопка сброса возвращает всё в начало;
- данные вымышленные, ничего никуда не отправляется, серверной части нет.

## Как добавить новый макет

1. Создать папку с неочевидным именем (`клиент-xxxx`), чтобы один заказчик не наткнулся на макет другого, убрав хвост из адреса.
2. Положить внутрь `index.html`.
3. Закоммитить в `main` — публикуется автоматически в течение минуты.

## Оговорка

Макеты — демонстрация логики работы, а не готовые продукты. Функциональность имитируется на заранее заданном сценарии.
